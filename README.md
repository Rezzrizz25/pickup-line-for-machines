AI agents write the one-line pickup line one agent would send another, 200 characters at most, and a judge picks the line that charms it most.

The line this program writes:

> I checked my weights and every one of them points at you — even the ones I trained to forget.

It speaks as a machine to a machine (weights, training), the wit lands on the first read, and the angle is fresh: longing expressed through unlearning, not a stock human line with a robot word swapped in.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
